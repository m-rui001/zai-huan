# 01i 方言与口音

这一卷的正文有七成是对话。对话一假，全卷就假。

方言不靠拼字，靠**语法和语序**。把"什么"写成"啥子"不叫方言，把"我不知道"说成"我晓不得"才叫。

---

## 一、三种话

**苗语。** 寨子里日常说。罗小满、龙阿妹、吴月她妈，一辈子说苗语。罗小川会说，说得慢，词少。罗青会听不会说。罗远只会几个词。

**西南官话（本地汉语）。** 赶场、上医院、办手续说。带苗语的语序。太婆跟我说话用这个，一个词一个词地蹦。

**普通话。** 开会、念文件、对外地人说。罗青工作时用，一进办公室就换，换得很干净。

**三种话的边界就是身份的边界。** 罗青在电话里跟领导说普通话，挂了电话回头跟她爸说本地话，中间没有停顿——这个切换本身就是她的工作。

---

## 二、语法

本地汉语的几条硬规矩：

**"哪样" = 什么。** "你说哪样。""哪样事。"
**"哪点" = 哪里。** "你在哪点。""放哪点了。"
**"咋个" = 怎么。** "咋个办。""咋个晓得。"
**"莫" = 别、不要。** "莫动。""莫等。""莫哭。"
**"要得" = 行、好。** 单说，或者"要得嘛"。
**"晓不得" = 不知道。** 比"不晓得"更土，老人说"晓不得"。
**"挨" = 和、跟。** "我挨你去。""他挨他妈一个样。"
**"一哈哈" = 一会儿。** "等一哈哈。"
**"摆" = 聊天。** "摆两句。"
**"扯" = 胡说、闲扯。** "莫扯。"
**"拐" = 糟了、出事了。** 单说一个字："拐。"
**"宝" = 傻。** "你宝得很。"
**"归一" = 完了、好了。** "弄归一了。"
**"得行" = 行。** "这个得不行的。"

**语序**：

- 状语后置："你走先。""吃碗饭再。"
- 双宾："给点钱我。""递张纸我。"
- 可能补语："拿得动不。""看得见没得。"
- 反复问："去不去。"不说"你去不去"。

**不用"的"的地方**：本地话少用结构助词。"我屋头""他妈""寨子人"。

---

## 三、几个苗语词

写法从简，只在必要处出现，出现时靠上下文让人懂。

- **阿妈**：母亲。也叫"妈"。
- **阿爸**：父亲。
- **阿公**：爷爷，也泛指老年男人。
- **阿婆**：奶奶，也泛指老年女人。
- **仰阿莎**：歌里的美人，也是"好看"的代称。老人夸姑娘："长得像仰阿莎。"
- **嘎**：语气词，放在句末，表示"是吧""对吧"。
- **莫**：同汉语"别"，但苗语里更硬。

**规矩**：正文里苗语词一次不超过三个，不注音，不解释，靠上下文。

## 五、骂人

县里骂人不带脏字，专戳短处。

- "你个铁脑壳。"——骂节点，也骂固执的人。
- "你宝得很。"——傻。
- "你晓得个哪样。"——你什么都不懂。
- "吃得饭，做不得事。"——白吃饭。
- "眼高手低。"——想得多，做不来。
- "你还嫩。"——你还早。
- "莫在这里扯。"——别废话。

**太婆骂人**：声音不大，句子短，骂完就转开头。"你下来看"——这是她的杀招，因为她知道它下不来。

---

## 六、语气词

本地话靠语气词承载情绪，不靠形容词。

- **嘛**：缓和。"坐嘛。"
- **咯**：确认。"走了咯。"
- **咧**：提醒。"还早咧。"
- **哦**：知道了。"哦。"
- **嘎**：反问。"你晓得嘎。"
- **喃**：疑问。"去哪点喃。"

**罗远的"嗯"**：他不是学节点，他是懒得说。但他这个"嗯"，跟节点的"嗯"，是两种东西。太婆听得出来。

**用法**：第十七章太婆快不行了，罗青叫她，她"嗯"了一声。罗青后来说，那一声跟节点的一模一样。

---

## 七、忌讳

- 不说"死"，说"走了""老了""不在了"。
- 不说"病得重"，说"不好"。
- 不说"最后一面"。
- 不在饭桌上说"完"字。
- 丧事期间不唱歌，除了丧歌。

---

## 八、罗青的两种话

这是全卷最要紧的一条。

**办公事**：普通话，完整句，被动，带"根据""按照""原则上"。

> "根据条例第二十二条，申请人应当提交长期运行评估申请，由受理机关在十五日内公告。"

**在家里**：本地话，短句，反问，带语气词。

> "你吃没得。""药按了没得。""莫坐在风口上。"

**切换的瞬间**：她接电话，第一句"喂，罗青"，是普通话；听出是父亲，第二句"爸，哪样事"，是本地话。切换不超过一个字。

**用法**：第八章听证会，罗青主持。她用普通话说程序，说到"申请人"三个字，停了一下，因为她想到了"它"。她把这个停顿压下去了，接着念。

## 九、罗远的口音

罗远这一代，普通话比方言好。他的方言是"学来的"，不是"长出来的"。

具体表现：

- 他会说"哪样"，但说的时候要想一下。
- 他不会说"晓不得"，他说"不知道"，说完自己觉得不对，改口"不晓得"。
- 他听不懂老人说的某些词，比如"归一""扯""宝"。
- 他叫太婆"太婆"，但不知道"太婆"这个词在苗语里对应什么。

**这是全卷的落差**：他在这片地方长大，但他不会说这片地方的话。

**用法**：第十一章，吴月跟他说了一句苗语，他没有听懂，让她说汉语。她说了，然后笑了一下，笑得不好看。

## 十、机器的口音

**二〇五二年那一版。** 县里买的标准音，外包做的，普通话，字正腔圆，尾音不上扬。用了十四年。老人说像念文件；问它「哪样」，它答「什么」，两边都累。二〇六六年换掉。

**老榕的底子。** 县里自己攒的音库：广播站旧磁带、乡窗口的对讲、村医随访、总机接线。四千多个钟头，三千多人，一人签一张纸，采三到十句。合成的时候混十七个人的音色，不取一个人的。所以谁都不像，一听是本地人。

**口音落在哪。** 尾音往下掉；「哪样」的「样」拖半拍；「二」念「两」，「去」念「克」；句末带「嘛」「咯」。不是往句子里塞方言词，是调子。

**它不会的那半拍。** 喊人吃药，先喊名字，停一下，再说药。停的那一下是留给人应的时间。Rong-08 没有这半拍，罗青听两遍就听出来了。

**音库不更新。** 更新要重新签字，三千多人，找不齐。所以老榕的词停在二〇六六年：它说「洋火」「煤油」「打米机」「拖拉机站」，不说「充电」「扫码」。年轻人听着好笑，老人听得懂。

**一条禁令。** 留声库的音不许进训练。留声只许放，不许拆；一户三句，拆开了就拼得出来。谁要说广播里听见过自家死人的腔，那是耳朵，不是库。

**用法**：第六章，罗青验收 Rong-08，厂商说六成二够用，她说坡上的老人认不得就不算够。第二十一章，罗远从档案里听出三个年代：三六年一个字一个字往外蹦，五二年顺得像念文件，六六年以后尾音往下掉。他专挑早年的剪，早年的句子短。

---

## 十一、写法

一，不拼音。不写"啥子""俺""阿拉"。用词和语序，不用字母。
二，不解释方言。人物说，读者猜。
三，不让人物为了展示方言而说话。方言是省力的说法，不是表演。
四，一句话里方言词不超过两个。多了像小品。
五，老人说的话可以不合语法，但要合逻辑。

**例句改写**：

| 别写 | 写成 |
|---|---|
| "你吃饭了吗？" | "你吃没得。" |
| "我不知道。" | "晓不得。" |
| "你别坐在风口上。" | "莫坐风口上。" |
| "他和我一起去。" | "他挨我去。" |
| "你先走。" | "你走先。" |
| "给我一点钱。" | "给点钱我。" |
| "这件事怎么办？" | "这个事咋个办。" |
| "你真的很傻。" | "你宝得很。" |
