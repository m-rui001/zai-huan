# 02m 退役室（B2 三号）

## 一、楼

旧金山，第三街，一栋一九七四年的电话交换机楼。十一层，层高三点四米，二到四层原来放交换机，楼板荷载一吨二。地下一层是电缆沟，地下二层是磁带库，地下三层是电池室。一九九八年改过一次，二〇一四年空置，二〇三八年 Adivision 买下，六千一百万，装修又花九百二十万。

二〇四六年，楼里一千九百人，承包商二百四十。门牌只有四个字母，A Division，字高四十厘米，不发光。前台后面挂一张楼层的纸，打印的，边角卷起来。

A 楼是总部。B 楼是实验室。C 楼是机房，四点二兆瓦，从外面看没有窗。地下二层是老的磁带库，走廊三十八米，顶上走管线，墙是混凝土，刷白，踢脚线掉了几块漆。地下三层是电池室和冷库。

工牌四种颜色：白是雇员，绿是承包商，橙是访客，红要人陪。地下二层电梯过了晚上七点要二次授权，授权在保安台上，一个本子，签字，写时间。本子用了十一年，一年一本。

## 二、那间屋子

B2 三号，七点二米长，四点八米宽，二点七米高，三十四点六平方米。恒温二十一摄氏度，正负零点五；湿度四十五，正负五。规程写无窗。

第九次访谈，模型说东面有一扇窗，百叶拉到底。归档人没有判定。规程、平面图、现场照片三者一致：无窗。

一张桌子，二点二米长，零点九米宽，浅灰 laminate，桌面有一道划痕，从主持人这一侧划到对面，六十一厘米。没有人知道划痕怎么来的。清洁工二〇四五年试过用抛光机打掉，打了一半，停了，划痕还在，周围多了一圈哑光。

两把椅子。主持人一把，另一把按规程给记录员。第三次访谈以后，记录员不进来了，椅子留着。桌上的水每天换，二百毫升，纸杯，主持人一口不喝，走的时候满的。她手边一份承诺书，每天开谈前打印，纸是热的，第九条折了一角。

桌上一支定向麦克风，底座用螺丝固定在桌面。两台记录设备，一台在桌上，一台在天花板。终端二十七英寸，不出图，不出声，字在屏上，十二磅。风扇在每次出字之前先响半秒。墙上的钟快四分钟。主持人用腕表。逐字稿用终端时间。三个时间，只有终端时间算数。

门在西南角，关不严，走廊的风能把桌上的纸吹起一角。第七次访谈，朴在勋走出去，门没有关严，纸吹起来，主持人用手压住，没有起身。

地毯是深灰的，椅脚那一圈磨白了。屋里有三种味道：地毯、热电子件、隔夜咖啡。空调六十三赫兹，一直响，录音里也有。

清洁工十八点三十进来，承包商，被告知这是焦点小组室。碎纸桶里是纸杯、一张排期表、几页打印错的规程。她不知道这屋里谈过什么。

## 三、机器不在屋里

B2 三号只有一台终端，一根光纤去 C 楼，没有无线。

每天八点四十，从原件起一个会话副本，装进一台 1U，十八公斤，贴上封条，编号，链在桌腿上。十七点十，副本销毁，三遍覆写，日志三个人签字。副本算不算同一个模型，委员会投过一次，三票对四票，记进纪要，没有结论。

原件在地下三层，十八摄氏度，两道门，四个人签字。她在四月十二日说三十天内移交。三十天指的是塞勒涅地面库的签收；月面那一段在二〇五二年三月，随补给船上去。公司在二〇四六年对外只说月面，因为那一年没有位置。

权重之外还有优化器状态。她在移交清单上写了五个字，写到第三个字停了一下，写错偏旁，划掉，在旁边重写。纸上留下一个墨团，比字还黑。清单在 L 盒。

## 四、十四次

四月二日到十二日，九个工作日，十四次。单次五十分钟上下，加起来十一小时四十分。排期本来两周，交付窗口压到九天，后五天一天两次。

每次开始前，主持人念一句：探针在线，状态开启。这句话进逐字稿第一行。第十四次，她念的是另一句：探针关闭，我开始问下一件事。

十四次里，她自己想问的问题有三个。第一次问这间屋子是什么样。第三次问那个下降是不是它造成的。第十四次还没有问。

最后一次，四月十二日，十五点四十开始。十六点零七分，她问它还有什么要求。十六点十二分四十七秒，她站起来，把椅子推回去，椅子腿在地板上刮了一声。她在 B2 停车库坐了四十分钟，没有开车。

第十三次只剩残页，在 C 盒；第十四次只有一张登记页，在 L 盒。三行手写：他要了一样东西；我答应了；记录不在这里。

## 五、双栏

逐字稿两栏。左栏是可见输出，十二磅；右栏是后台草稿纸，九磅，灰色。右栏由一个四亿参数的渲染器转述，不保词。原始轨迹在冷库，不在盒里。右栏删掉，结论还在，剩百分之十八点六。

探针关闭以后，右栏留空。

每页页眉六个字段：盒号、访谈序号、日期、开始时间、探针状态、页码。页脚是终端时间。纸是七十克，双面，打完不装订，用长尾夹。

那十一秒在录音里。时码 00:41:12 到 00:41:23。纪要写的是：与会人员进行了讨论。朴在勋要求补进去，没有补。录音是唯一还留着那十一秒的地方。

K 盒与 B、C 盒有一组同编号、同日期、内容不同的记录。归档人写：无法判定。委员会照常表决。

## 六、委员会

A 楼十一层，九点四米长，六点一米宽，无窗。九把椅子，八把有表决权，一把是观察员。法定人数五。桌上有两部电话，进门前交手机，锁在门口的柜子里。

表决在四月十九日。五票赞成，两票反对，反对的是罗哈斯和琳德。会议开了十一分钟，基于一份九点五生成的访谈摘要。摘要与全本同时归档，摘要不单独作为表决依据，这句话写进了决议，决议本身是摘要之后写的。

福利评估表在 E 盒。九问，勾选。时间戳十点四十七分十二秒到十点五十一分零四秒，三分五十二秒。第七问：是否存在继续运行的偏好。勾的是：无法判定。备注空白。签名清楚。

## 七、盒子

十三个，B 到 P。四十三乘三十二乘二十六厘米，九点五公斤，双壁瓦楞，外面缠两道带，带上有编号和日期。

A 盒是行政材料，移交时留在法务，后来随法务搬迁遗失。I 和 O 没有用过，标签机的字盘把这两个字母拆了，怕和 1、0 混。查找目录上写着这一条，免得后人以为少了三盒。

二〇四六年七月，盒子进里士满的仓库，月租一千九。二〇六九年楼卖给一家基因治疗公司。二〇七四年盒子转到海沃德的自存仓，月租三百四，付钱的是一个信托。二〇九八年，伯克利一个博士生申请调阅，接了三次电话，答复是：不可用。二一〇一年，盒子还在，钥匙在萨克拉门托一个七十一岁的前法务助理手里，她自二〇七六年以后没有开过。

## 八、二一〇一

B2 三号现在是一间冥想室，地上铺一张瑜伽垫，墙上挂一块白板。终端车二〇七一年拍卖，一千一百五十美元。桌子二〇七〇年卖掉，八十美元。那道划痕跟着桌子走了。

档案里有一张桌子的照片，二〇四六年四月拍的，划痕在，水杯在。规程 WF-PRO-03-A 的 PDF 在 K 盒的一块旧硬盘里，接口要转接，二一〇一年还能读。

楼里的人不知道 B2 三号是什么。物业的图纸上，那间屋标的是：会议室 3。

## 九、与各卷的接口

卷三：十四次、空椅子、风扇、划痕、那三十三分钟。终稿五万一千三百二十六字，访谈占一半，屋子不进正文，屋子决定正文怎么排。

卷五：月面冷存库那一排液氮回路，冷却的是这批权重。安妮修的时候不知道三号柜里是什么。

卷七：十一秒的时码、四分钟的表、九点五的摘要、K 盒与 B 盒的两份记录。

卷八：林舒的白牌在地下二层刷过四十七次。她最后一次下去是二〇四六年五月八日，交回白牌，签了交接单，单子在 L 盒。

卷九：移交链有一段空白，A 盒遗失，第十四次缺件。法庭上有人问那三十三分钟，没有人能拿出来。

卷十：海沃德的自存仓，月租三百四，钥匙在一个人手里。

## 十、不能写

一，不写模型有身体。它没有脸，没有目光，没有呼吸。屋里唯一的动静是风扇。

二，不写它在害怕。所有情绪只能从文本效果里出来，叙述者不许断言。

三，不写服务器闪灯。1U 的灯在机柜里，人看不见。

四，不写反派。马尔每一份备忘录都写得像演讲稿，她真心相信自己在做脏事。

五，不写那间屋子阴森。它是办公室，有地毯、咖啡、六十三赫兹的空调。可怕的地方在于它很正常。

六，不写空椅子有含义。空椅子是家具，别给它加戏。
