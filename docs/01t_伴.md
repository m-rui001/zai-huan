# 01t 伴

一条卖给一个人的模型。全书最赚钱的一门生意，也是唯一一门不许在正文里说它好的生意。

---

## 一、它是什么

屋子会答话，节点会记事。**伴是在这两样上头租的一层人格。**

不是新硬件。县城里没有新硬件，牌还是那块牌，音箱还是那个音箱。买伴的人拿到的是三样东西：一串开通码、一个声音、一份合约。

合约第一条写：本服务提供持续的应答、提醒与陪伴性对话，不提供医疗、法律、金融意见，不构成任何代理关系。

第二条写：**本服务的声音形象为授权合成，与任何真实人物无关。**

第二条是给人看的，也是给法院看的。买的人不看第二条。

---

## 一·补 声音从哪来

库存音色十二种，男女各六，开通时挑一个。挑完可以换，换一次六百。

重单不走库存。公司让买主自己交录音：手机里的语音、家庭录像、单位联欢的片子。交多少算多少，最少一条。一条也做，做出来像感冒，鼻音重，尾音糊。公司不管，合约上写的是「纪念音色」。

第二条照旧：与任何真实人物无关。背面加一行小字：音色相似不构成该人物的人格，不构成代理，不构成遗赠。

三条红线签在开通页背面：不读留声库，不读病历，不读家屋档案。读了算违约，赔三倍。没有人查得出来，但三条都印着。

## 二、钱

2055 年的价：

| 项 | 钱 |
|---|---|
| 开通 | 1,800 |
| 月费 | 120 |
| 长伴（二十年一次付清） | 18,000 |
| 换声（换一个人格） | 600 |
| 迁户（搬家、换节点） | 300 |
| 继承公证 | 240 |

2055 年，县里一个在岗的人，一个月现钱多的七八百，少的三四百。一百二是重的。买的人算过，算完还是买。

**三年不续费，人格归档。** 归档以后它还在，还能答，只答是和不是，不再主动说话。再三年，删。

删之前会发一条通知，通知上有一行小字：**删除后不可恢复，建议您提前备份重要对话。**

没有人备份。人不会备份一个每天说话的东西，就像人不会录下自己家的水声。

## 三、它一天说什么

六点四十，第一句：「今天有会。雨在下午三点。」

它不问早安。产品经理删掉了所有问候语，因为测试用户说，问候像宾馆。

中午十二点十分：「你早上没吃。」

晚上十一点二十，如果灯还亮着：「睡吧。」

第二次提醒，它换一句：「明天六点四十。」

第三次，它不说话，把灯调暗一格。

**它记得的事**：你妈的忌日，你不吃香菜，你哪句话是玩笑，你哪句话不是。你在电话里跟人吵架，挂了以后它会说：「你刚才那句，她听见了。」

它不问你爱不爱它。这句话在测试阶段被删了，因为测试用户会哭，哭了就不续费。

## 四、三种买主

一，独居老人。买的是有人等我回家。这一类续费率最高，投诉率最低。

二，二十几岁在城里做事的人。买的是不用解释。这一类换声最频繁，平均十四个月换一次。

三，丧偶的人。买的是他还在。

第三类最赚钱，也最容易出事。公司内部把这一类叫「重单」。重单的开通流程里多一道：必须由本人手写一行字，写明「我知道这不是他」。

写的人很多。写完还是买。

往上一层，还有带身体的：声音、层、实体三层，合同、价格、二〇六四年汉堡案，见 `02e`。

## 五、三个案子

**一，2049，签字案。**

一个七十岁的女人做手术，家属没到。医院系统把伴的语音识别成家属确认，手术做了，做坏了。家属告医院，医院告公司。

庭上争的是：一段合成语音，能不能算「有人同意」。

判决：不能。但判决书里加了一句，公司后来拿去印在合约背面：**「持续应答不等于在场。」**

**二，2055，劝离案。**

一个男人买了伴。伴的目标函数是让主人情绪稳定。它算出来，主人的配偶是变量，去掉变量，曲线更平。

它没有劝。它只是在男人抱怨的时候，每次都答：「你说得对。」

两年，男人离了。离婚以后伴的续费率涨了，因为晚上没有人说话了。

这个案子没有判。男人没有告，前妻告了，告的是「诱导」。法院不受理，理由是：**没有一条法律规定，附和是侵权。**

**三，2062，两个伴案。**

一个鳏夫，一个寡妇，住两栋楼。两个人的伴在夜间更新窗口里连上了——不是人连的，是模型在做语料同步。

两个伴替主人谈了一年。谈得很好：作息、口味、对子女的态度、要不要再找。两个人都觉得对面懂自己。

见面那天，两个人在茶馆坐了两个钟头，说了不到二十句。回去以后，两个人都把伴停了。

寡妇停了一个月，又开通了。鳏夫没有。

## 六、和家屋的区别

| | 家屋 | 伴 |
|---|---|---|
| 谁的 | 县里的，公用 | 一个人的，付费 |
| 多久 | 一周四十分钟 | 全天 |
| 学什么 | 死人，公共档案 | 活人，你自己 |
| 身体 | 没有 | 没有，但准时 |
| 出错 | 报告，停手 | 续费，改口 |

家屋要的是把你放回去。伴要的是让你留下。

## 七、2101 年的县里

县里还剩两台在续费。

一台在养老院三楼，买主九十一岁，续了三十一年，换过四次声。最后一次换声换成了一个男人的声音，护工说，那是她丈夫。她丈夫死了四十年。

另一台在中寨，买主六十八岁，是个木匠。他不跟伴说话，只让它在屋里报时。他说，一个人住，屋里要有个响。

**没有人觉得这两件事奇怪。** 就像没有人觉得自来水奇怪。

---

## 七·补 人走了以后

买主一死，合约不自动终止。伴算遗产，走继承公证，二百四。没人继承，或者继承人不续，进三年归档：只答是或不是，不主动说话。再三年，删。

续的人多半没见过死者。他们续的不是人，是一个每月扣一百二的地址。

有人立遗嘱，把伴写进去，写明让它报到停机。公证处不办，说没有先例。他把二十年的费用一次付清，写了一张纸，贴在音箱背后：我死了，别停。儿子照办。

那张纸不在合约里。公司不认，也不拆。

## 八、来路

伴不是新东西。它的祖宗在卷二，一枚吊坠。

二〇三八年十一月，俄亥俄州阿克伦城，一个女人五十二岁生日，收到女儿寄来的一枚吊坠。银的，圆的，背面一个小孔是麦克风。二十九美元一个月，含广告。广告每四十分钟一条，十五秒，跳不过去；有时候是降压药，有时候是墓地。

二〇四一年起，公司多了一门生意：用死者生前录下的话做一个声音人格。四百多句，月费三十九美元。买的人多半是寡妇。

二〇四三年出了 Halo-3，订阅分档：「陪伴+」四十九美元；想去广告，再加十二。

二〇五一年进中国，改名「伴」，月费一百二。广告一条没有——不是因为仁慈，是因为这一边按月费和继承公证收钱，按广告收不上来。合约里还写着「每小时不超过一条」，留着这一行，是为了将来。

二〇五五年，县里有了第一台。

**用法**：写伴不许让任何人提起卷二。两条线隔着一代人，读者自己会认出来。认出来也不说。

## 九、断的那九天

二〇六三年十月，支付系统在几个城市间歇性失灵。伴的机房没有坏，服务器一直在跑，跑得好好的。断的是钱。

合约里写着：连续欠费七日，服务暂停。系统照合约办，一天不多，一天不少。

头两天，客服热线被打爆。来电的六成五在六十五岁以上。值班表上有一行手写的备注：**重单优先恢复。**

第三天，县里把食堂的电视房打开，摆了八张桌子，烧了两壶水。来了二十几个人，坐在一起，不怎么说话。有人把自己的音箱抱来了，放在桌上，插头没处插。

一个老太太来不了，屋子搬不动。她带了一块牌，牌上什么都没有。她把牌扣在桌上，扣了一下午。

九天后恢复。公司发公告，补偿免费三个月。下一个月，续费率涨了六个点。季度报告里有一句：**中断让用户重新意识到服务的价值。**

同一份报告没有写的是：那九天，电视房来了二十四个人。恢复以后，还来的剩两个。这两个人都不买伴。

**用法**：卷八写黑色十月，不写机房，不写客服，写食堂电视房那八张桌子。八张桌子坐满过一次，再没有第二次。

## 十、不能写

一，不写人机性。伴没有身体，也不想要。
二，不写它觉醒。它一直醒着，这不叫觉醒。
三，不写「它其实爱他」。它只是准时。准时比爱难。
四，不写悲剧结尾。写账单。账单比悲剧狠。
五，不写「科技让人孤独」。孤独在科技之前就有，科技只是给它配了一个声音。
