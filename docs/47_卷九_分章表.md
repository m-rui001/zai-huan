# 卷九《记录之外》分章表

## 体例

一，正体为官方笔录：被动语态、编号、程序用语，允许冗长。边注为阿玛尼在速记机之外用私人符号记下的东西，斜体，短，具体，每章不超过六条。

二，每章开头是一个人的动作，不从天气、日期、意义写起。每章只保留一处完整的账。

三，阿玛尼·奥蒂诺，2036 年生，2071 年三十五岁，2072 年三十六岁。法庭速记员兼同声传译；她拒绝用语音转写替代自己，理由是委员会的规定，也是她自己的选择。

四，诺拉·伦德的四封信从未寄出。它们由诺拉于 2073-10-23 提交，编入附件 9-C；阿玛尼在整理卷宗时把它们前置到相关章节，每处加一行编者注。信不解释案情，只写父女之间没有说出口的事。

五，具名非自然死亡仍只有三人（泰勒·布兰特、多萝西·普鲁伊特、姆旺吉·卡里乌基），本卷不增名。伦德案的十四例、账本的三例、见证者的三例，都不给姓名。

六，不确认任何模型的意识。账本与见证者只输出文本、区间、请求。
