# 卷八 插入章样章：六只盒子（华盛顿，2065年1月6日）

丹尼把第一只盒子放上推车，放好，退后一步看轮子。

盒子是桃花心木的，三十八乘二十六，高十五。空的重两公斤三，里面放一份证书，重两公斤四。六只排成一排，推车的板子有点翘，第三只的角悬空。他从口袋里摸出一张对折的硬纸，垫在角下。再推，轮子不响。

他今年二十六，在国家档案馆做运输，第三年。他父亲开卡车，开了三十年，教他两件事：装车先装重的，卸车先卸轻的。档案馆的车没有重的，最重的是铜版地图柜，一年动两次。这六只盒子，他一个月前练过三遍，空盒，来回走，走到闭着眼也知道第三只的角会悬空。

调拨单是露丝签的，事由栏写「联席会议要求」，件数栏写「六（6）份」。她把单子递给他的时候说，路上有人问，你就说六份，别解释。他问，解释什么。她说，解释两套。他问，为什么。她说，解释了他们更糊涂。

七点四十，他和同事把盒子装进厢车。车厢里有固定带，带子绕过盒子，扣在轨上。他拉了两下，带子不动。同事说，纸，不是玻璃，别勒。他松了一格。

八点二十到国会山。车停在西侧的地下入口，坡道下去，灯是黄的。一个警察在门口等，姓莫里森，看了他的证件，又看推车。

莫里森问，里面是什么。

他说，证书。

莫里森问，几份。

他说，六份。

莫里森说，六个盒子，六份。

他说，对。

莫里森说，打开一个。

他打开第三只。盒盖内侧贴着一张纸，打印的，写着亚利桑那，州长。证书在里头，一页，右下角一枚州印。莫里森看了一眼，没有伸手。他说，可以合上吗。莫里森说，合上。

安检机是新的，传送带比档案馆的窄。盒子一只一只过，屏幕上是一片灰，纸看不出形状。莫里森说，过得去。他问，要不要再开一只。莫里森说，不用，六只一样重。

十二点十分，盒子送到议长办公室隔壁的小间。长桌上铺了绿呢，六只盒子排开，盒盖朝上。秘书处的一个年轻人拿着一张表，一只一只对，对完签字。年轻人问，钥匙呢。他说，没有锁。年轻人说，那扣呢。他说，第三只的扣松，路上垫了纸。年轻人说，要紧吗。他说，不要紧，别拎那个角。

十二点五十，他进了众议院大厅的旁听席。旁听席在三层，玻璃隔音，声音从喇叭里出来，慢半拍。他找到自己的座位，靠边，能看见下面的台子。台子上有一张桌子，桌上放着六只盒子，盒盖都合着。

一点，木槌敲了一下。副总统兰德尔从侧门进来，穿深灰西装，手里拿着一个牛皮纸信封。他走到台前，没有坐下。他说，联席会议由我主持，请书记员点名。点名点了四十分钟。点到第三个州的时候，台下有人咳嗽，咳了很久，旁边的人递水。

丹尼旁边坐着一个女人，四十多岁，胸前挂着众议院的牌。她看了他一眼，问，你是档案馆的。他说，是。她说，我在这楼里干了二十二年，没见过六个盒子。他说，我也没见过。她说，你猜今天会怎么样。他说，不知道。她说，我也不知道。她说完，从包里拿出一小袋饼干，撕开，吃了一口，递给他。他拿了一块。

众议院退场，门关上。大厅里空了一半。旁听席上有人站起来，被工作人员按回去。丹尼看表，一点五十二。门再开，众议员回来，走得比出去快。书记员报数：二十七比二十三，接受议会名单。台下有人鼓掌，鼓了几下，被木槌压住。

参议院没有退场，就地投。五十三比四十七，接受州长名单。两个数报完，大厅里静了几秒。兰德尔把信封打开，里面是三张纸。他念了三个州的名字，宾夕法尼亚，佐治亚，亚利桑那。念完，他把纸放下。

他说，参议院议长没有权力决定哪一份证书是真的。两院意见相反，依法不计。他引了一八八七年《选举计数法》第十五条，又引二〇四六年修正案第七条。两条都写着同一件事。他说，两条都没有写两院相反的时候谁定。

旁边的女人低声说，不计，就是四十六票不算。他说，那谁赢了。她说，谁也不够。他说，那怎么办。她说，二十号见。

台下有人喊，程序问题。兰德尔说，请讲。那人说，这个裁定应当记入议事录。兰德尔说，会记。那人说，什么时候。兰德尔说，现在。

书记员开始写。大厅里只有笔尖的声音，还有暖气的风。丹尼看见台子上那六只盒子，一只也没有开。证书还在里面，盒盖上的铜牌对着灯，反光。

三点四十，休会。他从旁听席下来，走到小间。六只盒子还在桌上，绿呢上落了灰。他和同事一只一只搬回推车。第三只的扣已经松开，盒盖翘起一条缝。他把盒盖按下去，扣上。扣不住。他用一根橡皮筋绕了两圈，橡皮筋是从抽屉里找的，黄的，旧了。

四点二十，盒子回到档案馆。露丝在接收室等，桌上摊着登记本。她把六只盒子一只一只打开，看证书，看州印，看签字，看完合上。她问，数了吗。他说，数了，六份。她在登记本上写：一月六日，借出六份，归还六份。写完，笔没有水了。她从笔筒里拿了一支，试了两下。

他问，现在怎么办。她说，上架。他问，然后呢。她说，等一月二十日。

他问，等什么。她说，等两套就职演说。

他笑了一声，笑到一半停了。她看了他一眼，没有说什么。

六只盒子推回库房，放在第四十一排。第三只的橡皮筋他没有取，黄色的，绕了两圈。旁边的架子上是一八七六年的木盒，铜锁坏着，用一根绳子系住。他推车过去的时候，轮子响了一下。

灯灭了。他动了一下，灯又亮。他看见六只盒子的铜牌，一排，六个，州名和哪一套，字朝外。宾州那只的铜牌上，州名少刻了一个字母，两个 n 刻成了一个。他伸手摸了一下，字是凹的，边上有一道划痕。他没有跟任何人说。
