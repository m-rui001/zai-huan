# 卷十《针脚》分章表

二十三章。前十八章是地球，后五章是火星。

地球十八章，二十四节气按六次合并减到十八：惊蛰并春分，立夏并小满，夏至并小暑，白露并秋分，霜降并寒露，小寒并大寒。芒种、大雪、小雪、立冬各列一章。

小满那一格空着，给了人。

火星五章不用节气，用本地日。地球上那本日历在他离开那天就停了。

实写合计 158,417 字（地球 130,727，火星 27,690），为原定十五万五的 102.2%。**章长按轻重分配，不按 ±5%。**最短的一章三千六（小雪），最长的一章一万一千九（夏至）。过一万的有三章（惊蛰、立夏、夏至），低于五千的有四章（白露、小雪、大雪、火星第二十章）——这个不均等本身就是节奏。

视角只给四个人：罗远、罗青、罗小川、吴月。老榕只以对话、广播、日志出现，不给它视角。语言平实，对话为主，心理描写少；不用任何形式实验。

合并章的开头与结尾逐字锁定（取原两章的第一句与最后一句），中间重写。新写的第十五章（小雪）没有旧稿。

## 锁定说明

一，表里的「开头」是本章第一句，逐字；「结尾」是本章最后一句，逐字。合并章沿用原两章的首句与末句。

二，第十七章是全书最重的一章，也是唯一一章把表决与死亡放在同一夜。上午她还是活的，下午票数过了，夜里她按了那个按钮。三件事不许分章，分开就变成三件事；合在一起才是一件事：一个村子用一个人的死，换了一台机器的走。

三，第十八章把丧事与尾声压在一起，跨度从冬至后三天到次年立春。中间用概述带过四十天，不写过程。

四，罗小川的反对票投两次。第一次七比七，他以为自己赢了；第二次十一比五，他才明白那四票是被什么翻过去的。他签交接的时候手抖，签了三次——不是因为帕金森，是因为他签的是自己守过的那台机器。

五，最长的一章是夏至（11,886），不是冬至（8,519）。夏至长在程序：一个人的申请要经过多少人，多少张纸，多少个到场的和不到场的人。冬至短，因为它只做一件事——投票，然后死人。程序可以长，事情不能长。

六，第十八章和第二十三章的末句是同一句。隔了两章、两年、两颗星。要的就是这个：最后一针和第一针是一个针法。

## 结构说明

一，地球的高点在第十七章（冬至：表决与死亡同一夜），火星的高点在第二十二章（家屋破规）。两个高点相隔五章，中间不是下降，是换气。

二，第二十三章最后三分之一切回地球，同一时刻，二十二分钟的差。全书最后一句仍旧落在针上，不落在机器上。

三，火星五章不许比地球十八章华丽。同一套短句，只是密度高，事多，人少。

四，罗远在火星上不成长，不顿悟。他修泵，他关掉房间，他发两个字。就这些。
