# 01v 直达

## 一、是什么

颅侧硬膜下电极片，一千零二十四个触点，四乘四厘米。从耳后开一个三厘米的孔放进去，九十分钟，局麻加镇静。胸口皮下埋一块电池，一根线从颈侧上来。全重四十七克。

它不读心。它读的是「准备说话」的那一下：人在心里默念，喉部和舌头的肌肉会有极微弱的动作，电极抓这个。发一句话，得先在里头把这句话「说」一遍，一个字一个字。熟练的人一分钟四十个字，生手二十个，出错率一成。

出去的只有你存心说的那一句。别的它听不见。说明书第一条，加粗。

进来的是字。没有图，没有声音。字在颅骨内侧亮起来，很淡，闭着眼才看得清，像有人在很近的地方低声念一行。

电池十八个月一换，换电池要开刀。

服务叫「在场」。月费三百九，合约三十六个月，机器不要钱。现金买九千九。广告词四个字：**不用等了。**

**不能关。** 有「静默」，一次最多三十分钟，到点自己回来，回来时响一声。合约写的是安全需要：人在外头出事，得找得到。这一条投诉最多，也是所有改装的起点。

## 二、那头

工程师管那个常开的低速率通道叫「底噪」。它不传字，只传一个「线路通着」的感觉。没有内容，没有话。用过的人说，像屋里另一个人没睡。

这个通道是链路余量，不算功能。产品文档里它占半页，写在「链路保活」底下。没有人为它付过钱，没有人关过它。

病人后来给它起了名字，叫「那头」。

## 三、十年

二〇五六年，第一例，四个人，一个死于感染。
二〇五九年，欧洲和北美批了。
二〇六一年，消费版上市，六个国家。
二〇六五年，峰值，四十二万人。护士、司机、值守、保安、手术室器械护士，最多的是**工作里有大量等待的人**。
中国有自己的版本，协议不通，二〇六六年峰值一百一十万，二〇六七年厂商自己停了。

二〇六七年，集体诉讼。四万一千二百人，和解，每人上限三万美元，不认责。真正撑住的诉由很窄：合约写「终身维保」，小字写「维保网络存续期间」。赔的是手术，不包括手术之后的年份。

监护仪上那句「停止使用后可能对独处不适应，六到十八个月缓解」，写在同意书第十一页第六条，六号字。写了。是真的。所以欺诈不成立。

二〇六七年，本区最后一个维保点关门。二〇六八年，做电极片的产线转产。二〇六九年，最后一家运营商停掉补贴。县志上只有一行：本年，直达植入停止。

没有禁。保险不保，医院不做，没人再装。四件事，都很无聊，没有一件是伦理。

## 四、拆

拆比装难。电极片和硬膜长在一起，要剥。三小时，全麻，三千五，术后六周不能低头。

拆完的人里，四成开了安眠药，一成二因为「焦虑」再入院。公司内部管这个叫「空频」。

病人不这么叫。病人说，耳朵里少了一个人。一个人说，最难受的地方不在头，在他再也没法一个人待着。

二〇六九年以后，还在用的人成了孤儿。全球剩三个点换电，价格翻四倍，一万二。有人自己换，从网上买旧电池，在家开刀。二〇七三年报了十一起死亡，实际不止。

八年，换五次电，两万一千；校准十二次，七千二。加机器，三万七。

二〇七九年，本区最后一个有资质的拆除医生退休。之后要拆，得去外地，或者找一个没做过的外科医生。多数人不拆。一块死掉的电极片留在颅骨里，不疼，不长东西，每年过安检要说明一次。

## 五、它发出去的话不算日记

二〇六八年，一个离婚案定的。丈夫的直达记录被调出来作证。法院认定：经由直达发出的内容，在发出的一刻即到达第三方服务器，属于运营商的业务记录，不算个人私密通信。

判完，很多人第一次去查自己的记录存在哪。存在运营商那儿，保留五年，监管要求。

二〇七〇年，那家运营商按数据最小化规则清掉了历史记录。清得很干净，合规。

## 六、二一〇一

县医院的核磁登记表上有一栏：**体内有无植入物**。填「有」的，注明位置和型号。一年填不了几次。

养老院有两个老人，耳后各有一道旧疤，疤底下是断电三十年的电极片。护工知道，家属不知道，也没人问。做核磁要报，报了排到最后。

县医院还有一副给截瘫的人用，排队三年。机房几副工用目镜，戴上看得见线路图，摘下要签字。那两种是别的线，跟直达一起死。

铁盒和抽屉里有几十副眼镜，镜腿断了，没人会修。

老照片里有两类。一类是一桌人吃饭，每人眼前一块亮的东西，谁也不看谁，那是眼镜。另一类是一个人坐在桌边，眼睛睁着，没在看任何东西，嘴唇不动。背面写着三个字：在里头。

直达的照片很少。它不留影。

## 七、与各卷的接口

卷五：月面轮换前必须拆。辐射剂量和维保都算不过来，规程写死。有人瞒着没拆，上去三个月，静默超时，全站找了两天。

卷六：十一秒里，两种人的证词不一样。装过的人说得更细，因为他们当时在「那头」听见了系统的回话；没装过的人只记得安静。前一种证词后来被认定不可靠。

卷七：监控器读的是输出。直达把输出提前到了「准备说」的那一下，读到的更多，也更不像话。

卷八：晨昏线那年是峰值。基地里一半人装着，站规新增一条：值班不许开直达。

卷九：和解卷宗、离婚案、运营商清库，都在这一年被翻出来。有人问，那六年里跟他说话的是谁。没人答得上，记录已经按规矩清了。

卷十：核磁登记表那一栏，两个老人的旧疤。

## 八、不能写

一，不写读心。它只发你存心发的那句。
二，不写黑客入侵大脑。能改的是链路和计费，改不了人。
三，不写植入者变得冷酷。人没变，只是不再独处。
四，不写发光。字很淡，闭眼才看得见。
五，不写它失败于伦理。它失败于电池、维保点和一种说不出口的难受。
六，不写它填平了空档。它确实填平了，所以它必须死；这一卷的戏全在空档里。
