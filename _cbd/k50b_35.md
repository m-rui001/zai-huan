**A 叙述声替读者说破**

| 行号 | 原句 | 理由 |
|---|---|---|
| 18139 | 这个声音，跟三号渠的水声，是一个声音。 | 两处声音的对应由叙述者直接判成“是同一个”，读者不必自己去联想。 |
| 18263 | 他还学会了第四件：不问船。 | 给前面的三条清单补上第四条，并顺手把一条不成文的规矩升格为人物成长的结论。 |
| 18271 | 船走了以后，基地的人不提船。谁提，谁就是想家。想家在这儿不算病，可是也不能多想。想多了，就不干活。 | 四个短句串成一条因果链，把行为规范的道理一路讲到底。 |
| 18379 | 他这才想起来，这儿的重力小，血不流。 | 上一句刚给出“血不往低处流”的画面，这一句立刻把画面解释成一句物理结论。 |
| 18435 | 那些声音平时听不见，这会儿全听得见。 | 刚写出的静默又被补上一句注解，替读者点明这份“静”意味着什么。 |

**B 同一人物第三次重复**

| 行号 | 原句 | 理由 |
|---|---|---|
| 18203 / 18477 / 18495 | 第二页写了一半，停了。／他停住。／他写到这里，停了一下。 | 罗远“写到一半停笔”这一动作在三次写单子的场景里各出现一次，到第三次已不再带来新信息。 |
| 18393 / 18479 / 18581 | 何班长也来了，站在门口，没有进来。／何班长站在门口，没有进来。／何班长从里头出来，把门关上，站在门口，两只手垂着。 | 何班长“站在门口”这个场面三次出现，人物状态一次比一次更明确，动作本身却完全没变。 |

**C 表格、字段、清单式段落**

| 行号 | 原句 | 理由 |
|---|---|---|
| 18201–18203 | 第一页写泵的编号，拆下来的件，换上去的件，试转的声音。 | 整句由四个表单栏目的名字组成，只是把栏目名念了一遍，没有落到具体的东西上。 |
| 18215 | 罗远低下头，写：库房没有；新件要等船；明天没水；外头有一台废泵，轴承是好的；规矩说的是舱里头，不是墙根。 | 分号隔开的五条就是一张判断清单，以条目形式进到叙述里。 |
| 18233 | 小许三十四，毕节人，来这儿四年。他管所有的灯、所有的插座、所有的线。 | 年龄、籍贯、年资、职务依次排开，读起来像一条人事档案。 |
| 18261 | 他学会了三件事：一，走路要慢，快了会撞门框；二，螺丝要拧两遍，第一遍拧上，第二遍拧紧；三，东西坏了先拆，拆了再说。 | 标号、分号、并列三项，整体上就是一个条目化的清单。 |
| 18265 | 六点起，七点上工，十二点吃，一点上工，六点吃，十点熄灯。 | 时间与动作依次对应，没有缝隙，读起来像一张作息表。 |
| 18431 | 这是规矩，第六条。不干活，不说话，站着或者坐着。 | 先给出条款编号，再列出三项禁止内容，像条例原文。 |
| 18465 | 左边的钟面上有一道划痕，从十二点那一格划到六点，右边的玻璃上有一圈手指印，是换班的人每天按出来的；两个钟的秒针走得一样快，一声一声对着响，分针却一个在这一格，一个在那一格，隔着三十九分钟，走廊的灯在钟面上照出两个白点，一起亮，一起灭。 | 一句话里把两只钟的各个部件和状态逐项点过，顺序像清点一遍。 |
| 18533–18537 | 已阅。编号 R-5779-01。／请于三日内提交现场照片、设备检查记录、同班人员问询。／家属通知由属地负责。 | 三行回执直接贴进叙述，字段和语气都还是系统提示的格式。 |
